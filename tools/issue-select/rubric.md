# Rubric: is this a good first issue?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| Maintaining Status | repo's commit, release, pull request and issues activity  | maintainer has active commits, merged pull requests or  in the last 1 month  | required |
| Does not prohibit LLM contributions  | repo's documents, license, readme  | Does not have a policy that prohibits LLM/AI contributions in README, docs/ or any related files  | required  |
| Good documents for contributors  | repo's documents, readme, GitHub description, GitHub wiki  | well organized and actively maintained documents or manual that has section for contributors or developers  | preferred  |
| Clear description of the issue  | Issue title, description, comments, labels, assignee  | An issue that provides instruction for reproduction or rationale for new features  | preferred  |
| Clear status the issue  | Issue status and conversation   | Is an open issue, not marked as completed, is not linked to any previous issues  | required  |
| Open issues  | Issue status, assignee, development, labels  | is not linked to any open or closed PR, is not claimed by others in the comment  | required  |

## Verdict rule

Accept if every required check passes; Rank accepted issues by how many checks 
they pass; unclear check ranks higher than failed check if two issues pass the 
same amount of checks.
